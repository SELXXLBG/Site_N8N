# Freelance Nexus — Web Application

Application web pour la plateforme Freelance Nexus. Veille automatisée de missions freelance pilotée par IA (n8n + Groq).

## Structure du Projet

- `/index.html` : Landing page optimisée pour la conversion.
- `/missions.html` : Dashboard utilisateur pour consulter les opportunités matchées.
- `/profil.html` : Configuration des critères de matching (stack, TJM, remote).
- `/abonnement.html` : Gestion du plan et accès portail Stripe.
- `/login.html` : Interface de connexion sécurisée.
- `/css/` : Design system premium (Dark Mode, Glassmorphism).
- `/js/` : Logique applicative et intégration API n8n.

## Technologies

- **Frontend** : HTML5, CSS3 (Vanilla), JS (Vanilla).
- **IA/Automation** : n8n (Back-office), Groq (Enrichissement Llama 3).
- **Paiements** : Stripe Checkout & Customer Portal.
- **Hébergement** : Cloudflare Pages.

## Installation Locale

Ouvrez simplement `index.html` dans votre navigateur ou utilisez un serveur local (ex: Live Server sur VS Code).
