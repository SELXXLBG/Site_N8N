✅ Checklist Pré-Déploiement

  • Copier config.example.js en config.js
  • Remplir les URLs des webhooks n8n dans config.js
  • Configurer la clé publique Stripe
  • Tester toutes les pages en local
  • Vérifier le responsive (mobile/tablet/desktop)
  • Tester les formulaires (signup, login, profil)
  • Vérifier les liens de navigation
  • Valider le CSS (pas d'erreurs dans la console)
  • Tester le JavaScript (console sans erreurs)

🔧 Configuration Requise

Avant le déploiement, assurez-vous d'avoir :

  • Compte CloudFlare Pages créé
  • Workflows n8n déployés avec webhooks publics
  • Compte Stripe configuré avec les plans tarifaires
  • Google Sheets avec les données des abonnés
  • Domaine personnalisé configuré (optionnel)

🚀 Prochaines Étapes

  1. Compléter config.js avec vos URLs
  2. Tester en local avec un serveur HTTP simple
  3. Pousser le code sur GitHub
  4. Connecter CloudFlare Pages au repo
  5. Configurer les variables d'environnement
  6. Déployer et tester en production

🌐 Serveur Local

Pour tester le site en local, lancez un serveur HTTP :

# Python 3
python -m http.server 8000

# Node.js (avec http-server)
npx http-server -p 8000

# PHP
php -S localhost:8000

Puis ouvrez : http://localhost:8000
